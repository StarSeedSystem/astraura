# Astraura 1.58-bit — edición nube

Backend público de StarSeed OS: estado, memorias, enjambre y puente con Supabase.
La inferencia pesada sigue siendo local en cada neurona; esta nube es el punto de
encuentro para quien no tiene neurona propia.

- Código: https://github.com/StarSeedSystem/astraura
- OS: https://starseed-os.vercel.app
- Salud: `GET /api/status`

Los secretos (SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, R2, claves de IA) se
configuran en **Settings → Variables and secrets** de este Space.
